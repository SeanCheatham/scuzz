# ADR 0001 — GC v0

## Status

Accepted (Phase 0)

## Context

ScalUI needs a minimal native runtime. A full Immix/JVM-class GC is out of scope for bring-up.

## Decision

**v0 allocator: libc `malloc`/`free` with thin wrappers** (`su_alloc` / `su_free`). No moving collector yet.

- Strings and IO nodes are explicitly freed by the IO run loop / `Resource` release where ownership is clear.
- Panic paths may leak; process abort is acceptable in Phase 0.
- Conservative/precise bump + collections deferred until frame budgets and self-host pressure demand them.

## Consequences

- Simple FFI and debugging.
- Apps must not assume GC; Stage-0 stdlib avoids open-ended heap graphs without owners.
- Phase 2 View trees are explicitly owned (`su_view_free` / session `take_root`); signals are demo-owned. Revisit when long-lived interactive graphs outgrow malloc/free (bump + collect or refcount).
